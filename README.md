# 🛡️ File─Guardian 🛡️

## - תיאור הפרויקט:
המערכת מנהלת העלאה והורדה של קבצים מוצפנים, אימות זהות המשתמשים וניהול הרשאות הגישה לכספת. במקביל, היא מזהה תקיפות- כמו ניסיונות התחברות מרובים, גישה מכתובות איי-פי או בשעות חריגות, והורדה מסיבית ובלתי שגרתית של קבצים בזמן קצר, חוסמת ומתריעה עליהם למנהל.

## - FileGuardian מטרת המערכת:
המערכת נועדה לתת מענה לשתי בעיות מרכזיות:
1. **אחסון לא מאובטח של מפתחות הצפנה וסיסמאות:** המערכת מספקת רכיב ניהול סודות מאובטח, המצפין את הנתונים הרגישים בזמן מנוחה ומשחרר אותם לרכיבי המערכת המורשים בלבד בזמן אמת.
2. **חוסר יכולת לזהות ניסיונות פריצה בזמן אמת:** שילוב מנגנון ניטור בזמן אמת שמזהה אנומליות בהתנהגות המשתמשים (כגון ניסיונות התחברות מרובים או ממיקומים שונים) וחוסם את הגישה באופן אוטומטי.

# CyberVault – תשתית תקשורת מבוססת TCP (גרסה 1)

הגרסה הראשונה של תשתית התקשורת בפרויקט הכספת המאובטחת: שרת וקליינט מעבירים הודעות בפורמט מוסכם על גבי TCP. בשלב זה אין הצפנה, אימות משתמשים, אחסון קבצים או ממשק גרפי.

## מבנה הקבצים

| קובץ | מחלקה | אחריות |
|---|---|---|
| `protocol_message.py` | `ProtocolMessage` | הודעה אחת (פקודה + תוכן): יצירה, קידוד ל-UTF-8 ופענוח |
| `protocol_error.py` | `ProtocolError` | חריגה להודעה שאינה עומדת בפורמט הפרוטוקול |
| `protocol.py` | `Protocol` | שליחה וקבלה של הודעות שלמות על גבי TCP (כותרת אורך + גוף) |
| `network_server.py` | `NetworkServer` | האזנה, קבלת לקוח, טיפול בבקשות והחזרת תגובות |
| `network_client.py` | `NetworkClient` | התחברות לשרת, שליחת פקודות מהמשתמש והצגת התגובות |
| `test_all.py` | – | בדיקות אוטומטיות (pytest) |

## פורמט ההודעה

- גוף ההודעה: `COMMAND|data` בקידוד UTF-8. הפיצול הוא במפריד הראשון בלבד, ולכן `data` יכול להכיל את התו `|`.
- לפני כל הודעה נשלחת כותרת אורך של 4 בתים (big-endian) עם מספר הבתים של הגוף.
- TCP הוא זרם בתים ללא גבולות הודעות, לכן הקריאה נעשית לפי האורך שבכותרת בעזרת `__recv_exact`, שאוספת בדיוק `n` בתים בקריאות `recv` חוזרות.
- `MAX_LENGTH` הוא 1MB, כדי שהשרת לא ימתין לגוף ענק מלקוח פגום.

## פקודות נתמכות

| פקודה | תוכן בבקשה | תגובת השרת |
|---|---|---|
| `PING` | ללא | `PONG` |
| `ECHO` | טקסט חופשי | אותו טקסט |
| `TIME` | ללא | שעת השרת בפורמט `HH:MM:SS` |
| `EXIT` | ללא | `BYE`, ואז השרת סוגר את החיבור |
| כל ערך אחר | – | הודעת `ERROR` |

## טיפול בשגיאות

- **הודעה לא תקינה** (קידוד שגוי, מפריד חסר, פקודה ריקה): `ProtocolError`. הזרם עדיין מסונכרן, ולכן השרת עונה `ERROR` וממשיך.
- **ניתוק** (`ConnectionError`) או **אורך חריג** (`ValueError`): אי אפשר להתאושש, ולכן השרת מסיים את החיבור.
- **שרת כבוי**: `NetworkClient` תופס את שגיאת החיבור, מדפיס אותה ומסיים בלי לקרוס.

## הוראות הרצה

דרישות: Python 3.8 ומעלה. אין תלות חיצונית להרצת המערכת.

1. הפעלת השרת (בטרמינל אחד):

   ```
   python network_server.py
   ```

   השרת מאזין על `127.0.0.1:1729`, מטפל בלקוח אחד ונסגר אחרי `EXIT`.

2. הפעלת הלקוח (בטרמינל שני):

   ```
   python network_client.py
   ```

   מקלידים פקודה בשורה `Enter command:`, לדוגמה:

   ```
   PING
   ECHO שלום עולם
   TIME
   HELLO
   EXIT
   ```

3. הרצת הבדיקות האוטומטיות:

   ```
   pip install pytest
   pytest test_all.py -v
   ```

   הבדיקות מפעילות שרתים על פורטים 5001–5009, ולכן הפורטים האלה צריכים להיות פנויים.

## הערות

- השרת מטפל בלקוח אחד בלבד (`accept` יחיד). תמיכה בכמה לקוחות במקביל באמצעות Threads היא הרחבה לגרסה הבאה.
- פקודת הסיום במימוש היא `EXIT` (בטבלת הדרישות של דף העבודה היא מופיעה כ-`QUIT`).
